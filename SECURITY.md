# Security Policy

## Project status

LNAT-PQC is a **research prototype** for experimentation and cryptanalysis.
It is **not production software** and must not be used to protect real-world data.

## Reporting a vulnerability

Please report security issues privately by opening a GitHub Security Advisory in this repository:
<https://github.com/muhammadsohaimmuqtada/lnat-pqc/security/advisories/new>

If that channel is unavailable, open a private maintainer contact request via GitHub issue and avoid posting exploit details publicly.

## Scope

In scope:
- Implementation bugs in this repository
- Packaging, CI, and dependency issues that affect security or reproducibility
- Documentation issues that could cause unsafe usage

Out of scope:
- Production support guarantees or SLAs
- Security guarantees beyond what is explicitly documented
- Attacks requiring features that are not implemented in this prototype
